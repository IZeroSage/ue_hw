# ДЗ №1

## Управление

| Клавиши | Действие |
|---|---|
| W / A / S / D | Движение |
| Мышь | Вращение камеры |
| Space | Прыжок |
| Left Shift, удерживать при движении | Спринт |
| E | Взаимодействие: `Interaction triggered!` |
| Esc | Завершить Play In Editor |

## Реализованные требования

- `AMechanicsCharacter` непосредственно наследуется от `ACharacter`.
  Стандартный `BP_ThirdPersonCharacter` переподчинён этому классу.
  Камера, ходьба, поворот персонажа, прыжок и стандартные анимации шаблона сохранены.
- `IA_Sprint` и `IA_Interact` — настоящие Input Action ассеты типа Boolean.
  Они добавлены в `IMC_Default` на Left Shift и E.
  Обработчики привязаны в C++ в `SetupPlayerInputComponent` через `UEnhancedInputComponent::BindAction`.
  Спринт обрабатывает также `Canceled`, взаимодействие срабатывает один раз на нажатие (`Started`).
- `OnInteractionTriggered` — `Dynamic Multicast Delegate` с `BlueprintAssignable`.
  C++ вызывает `Broadcast`, а Event Graph персонажа подписывается на него в BeginPlay.
  Обработчик `HandleInteraction` вызывает Blueprint-узел `Print String` с требуемой строкой.
- Скорость ходьбы — **500 см/с**, спринта — **850 см/с**.
  `bIsSprinting` объявлена с `UPROPERTY(BlueprintReadOnly)`.
- В стандартном `ABP_Unarmed` Event Graph получает `bIsSprinting` из C++ персонажа.
  В машине `Locomotion` добавлено отдельное состояние **Sprint** со стандартной
  анимацией `MF_Unarmed_Jog_Fwd` и плавными переходами по `bIsSprinting` / `NOT bIsSprinting`.
  Вложенная машина прыжка, падения и приземления сохранена.
- Выносливость реализована в C++ с учётом `DeltaSeconds`: максимум **100**,
  расход **22/с**, восстановление **18/с** после паузы **1 с**.
  Она расходуется при спринте по земле с вводом движения. Стояние с Shift её не тратит.
  При нуле спринт останавливается даже с зажатым Shift. Для повторного спринта нужно
  отпустить Shift, восстановить хотя бы **15** и нажать Shift снова.
- `AStaminaHUD` показывает компактный HUD в левом верхнем углу: восьмиугольный
  медальон, красную декоративную полосу HP, синюю декоративную ману и рабочую зелёную
  стамину с числовым значением. При истощении появляется подсказка отпустить Shift.
  HP и мана остаются на фиксированных уровнях 82% и 68% и не имеют игровой логики.
  Полоски имеют заданные sRGB-цвета в центре: HP `(80,39,40)`, мана `(40,40,89)`,
  стамина `(65,92,63)`; верхние и нижние края светлее середины.
  Медальон — текстура `/Game/UI/T_SunMedallion` с прозрачным фоном;
  исходный PNG находится в `SourceArt/UI/SunMedallion.png`.
  HUD работает в игре, а не только через отладочные сообщения редактора.
